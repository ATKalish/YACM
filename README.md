# YACM
A desktop successor to tools like D&D Beyond and fillable PDFs for D&D 5e character management. Intended to be extensible, i.e. any user can create nearly whatever they want. Furthermore, intended to be such that homebrew content (user-generated) is treated in the same manner as RAW (rules as written) content is. Designed to not detract, diminish, distract, or abstract from in-person creativity.
